# Sales Prediction & Forecasting Model

## Project Overview
This repository demonstrates a predictive analytics workflow built with Python. By applying a Linear Regression machine learning model, this script helps businesses forecast future sales revenue based on projected advertising budgets.

## Tech Stack
* **Language:** Python
* **Libraries:** Pandas, NumPy, Scikit-Learn

## Business Impact & Use Case
* Moves beyond historical reporting to **forward-looking forecasting**.
* Optimizes marketing budget allocation by predicting return on investment (ROI).
